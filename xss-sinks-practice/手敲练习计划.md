# 手敲练习计划：把「漏洞汇点」练到条件反射

适合：**代码不熟、但想牢牢记住 XSS 相关写法**的人。目标不是当全栈工程师，而是 **看到/写出危险写法能立刻反应**。

---

## 先定一个现实目标

「闭眼都知道」分两层，建议分开练：

| 层级 | 你要达到的样子 | 大概周期（每天 20～30 分钟） |
|------|----------------|------------------------------|
| **A. 认路** | 听到 `innerHTML`、`v-html`、`dangerouslySetInnerHTML` 知道：**这是 HTML 汇点，未净化＝高风险** | 1～2 周 |
| **B. 手敲** | 不看资料能写出：**一行危险赋值 + 一行安全替代（textContent 或 sanitize）** | 在 A 基础上再加 2～4 周 |

代码基础弱时，**先 A 再 B**，不要一上来硬背长文件。

---

## 推荐节奏：四步循环（每一小段都这样练）

对 **同一个知识点**（例如「原生 innerHTML」）重复下面 4 步，比一次性抄十页更有效。

1. **看**：打开 `vanilla/index.html`，找到「危险」和「安全」按钮对应的那几行 `<script>`，读注释。
2. **抄**：对着敲一遍（允许看）。
3. **盖**：盖住屏幕 / 折起纸张，只凭记忆写出：**危险那一行** + **安全那一行**（`textContent` 或 `DOMPurify.sanitize`）。
4. **说**：用嘴说一句——**「为什么危险 / 安全」**（各一句话）。

某一天 **第 3 步写不出来**，就回到第 2 步，不要硬撑。

---

## 每天 20 分钟具体安排（示例一周）

**周一～周二：只练原生（最直观）**

- 新建一个空白 `drill.html`，只包含 `<div id="t"></div>` 和 `<script></script>`。
- 手敲并运行：
  - `document.getElementById('t').innerHTML = '<img src=x onerror=alert(1)>';`（本机）
  - `document.getElementById('t').textContent = 同上字符串;`
- 第三天起加一行：`t.innerHTML = DOMPurify.sanitize('...');`（先复制 CDN 那行 script，CDN 可以照抄）

**周三：默写「三张卡片」**（写在便签上贴桌子）

背到能默写英文关键字即可：

```
危险：element.innerHTML = 用户数据
纯文本：element.textContent = 用户数据
富文本：element.innerHTML = DOMPurify.sanitize(用户数据)
```

**周四～周五：对照框架名字（只背模式，不写完整项目）**

默写/口述模板（不要求运行）：

```
React:  dangerouslySetInnerHTML={{ __html: ??? }}
Vue:    <span v-html="???"></span>
```

心里把 `???` 换成：**未净化＝危险；净化函数(数据)＝加固思路**。

**周末：5 分钟总复习**

- 闭卷写：**3 个汇点名字** + **1 个安全替代**（textContent 或 sanitize）。

## 「完全掌握漏洞点」最小必背清单（先背这 7 条）

能按顺序说出来就够应付大部分审计脑子：

1. **字符串进了会被当成 HTML 解析的地方** → 可能是 XSS 汇点。  
2. **`innerHTML` / `outerHTML`**：原生 DOM。  
3. **`dangerouslySetInnerHTML`**：React，属性里是 `__html`。  
4. **`v-html`**：Vue 模板。  
5. **渲染函数里的 `innerHTML` / `domPropsInnerHTML`**：和上面同类。  
6. **只展示字**：优先 **`textContent`** 或服务端 **HTML 实体编码**（你们 `server.js` 的 `htmlEscape`）。  
7. **要保留标签**：**白名单净化**（DOMPurify / 公司 filterXSS），不是只 `encode` 整段富文本就完事。

---

## 不要这样练（容易放弃）

- 一次抄完整 `server.js` / 整份接入指南 → 记不住，只练 **5～10 行** 的块。  
- 从不运行 → 每敲完一小块 **保存 → 浏览器打开 → 点按钮看现象**。  
- 和「学完整 JavaScript」绑死 → 你现在练的是 **安全模式**，语法边用边查即可。

## 自测：什么时候算「这一关过了」？

连续 **3 天**，不看资料能完成：

1. 写出 **`innerHTML` 危险赋值** 和 **`textContent` 安全赋值** 各一行。  
2. 说出 **React / Vue 各一个危险 API 名字**。  
3. 说出 **富文本时为什么不能只靠 `htmlEscape` 整段**（一句话：要白名单净化）。

做到再进阶 webpack/babel 接入；那是工程化，和「漏洞点条件反射」可以分开学。
