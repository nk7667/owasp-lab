# 反射型 XSS — 怎么「手敲」练？

## 先澄清：不是「只有浏览器里的 JS」

`server.js` 跑在 **Node（服务端）**，语言也是 JavaScript，但角色是：

- **读请求**：`req.query.q`（浏览器地址栏 `?q=...`）
- **拼 HTML 字符串**：模板字符串里的 `${q}` 或 `${htmlEscape(q)}`
- **发响应**：`res.type('html').send(...)`

浏览器收到的是 **一整页 HTML**，再自己解析。  
所以：**反射练的是「服务端（或任意后端）如何把 URL/请求里的数据写进响应」**；用 Node 只是其中一种实现，和「DOM 练习页里那种 `innerHTML`」不是同一层。

---

## 手敲练什么就够了？（按块默写）

每天选 **一块**，「看 → 抄 → 盖 → 说」：

1. **`htmlEscape` 函数**（`replace` 那几行）  
   - 说清：在 **HTML 正文**里输出前为什么要转义 `& < > " '`。

2. **`/vuln` 路由整段**（约 4 行）  
   - 关键：**`${q}` 不转义**。

3. **`/safe` 路由整段**  
   - 关键：多一行 **`const safe = htmlEscape(q)`**，div 里用 **`${safe}`**。

4. **（可选）** `app.get` + `req` / `res` / `listen` 骨架  
   - 能默写「最小 Express 监听 + 一条 GET」即可，不必背整个 `pageShell`。

环境：`npm run dev`（`node --watch`）改 `server.js` 可自动重启。

**仓库默认**：`server.js` 为 **TODO 骨架**，完整实现见 **`server.reference.js`**。卡住时在另一终端运行 **`npm run answer`** 启动参考答案（不占同一端口时需先停掉 `dev`）。

## 还要不要练「别的语言」的反射？

**学 XSS 概念：不必。**  
反射型在 PHP / Java / Python / Go 里都是同一句话：**请求里的数据 → 进响应 HTML → 要按上下文编码**。

- **只练 Node**：足够建立条件反射（`query` → 拼 HTML → `encode`）。  
- **工作上用 Java**：以后再对照把「拼字符串」改成 Thymeleaf 转义、`StringEscapeUtils`、或模板默认转义——**规则一样，语法不同**。

进阶想加「反射的全面性」，优先加 **不同输出上下文**（例如属性、`href`），而不是先换十种语言。

## 和 DOM 练习的分工

| 练习 | 你主要在记什么 |
|------|----------------|
| **反射**（本目录 `server.js`） | `req.query`、拼进 **响应 HTML**、**htmlEscape** |
| **DOM**（`xss-sinks-practice/vanilla`） | `getElementById`、**innerHTML / textContent**、sanitize |

两条线都熟，审计时才能同时想到：**数据是服务端吐出来的，还是前端 JS 写进去的。**
