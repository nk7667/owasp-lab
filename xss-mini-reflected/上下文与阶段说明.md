## 阶段 1：同一参数 `q`，五种「落点」（输出上下文）

核心一句话：**不是「转义一次管全部」，而是「数据最后落在 HTML 的哪一类槽里，就用哪一类规则」。**

### 1）HTML 正文（元素之间的文字）

- **拼法**：`<div>${q}</div>`
- **风险**：`q` 里的 `<`、`script`、`img onerror` 会被当成 HTML 解析。
- **常见修**：**HTML 实体编码**（你们的 `htmlEscape`）— 只保证「当纯文字插在标签中间」时大体正确。
- **路由**：`/vuln`、`/safe`（已有）。

### 2）HTML 属性值（双引号里）

- **拼法**：`<div title="${q}">…</div>`
- **风险**：`q` 里若有 **未编码的 `"`**，会 **提前结束属性**，后面可以伪造新属性（如事件）→ **属性注入**。
- **和正文的区别**：除了 `<>`，**引号 `"`（及上下文相关的 `'`）** 更要命；规则叫 **attribute encoding**，双引号属性里通常要处理 **`"` `&` `<` 等**（你们用同一套 `htmlEscape` 在本 demo 里可演示引号被转义）。
- **路由**：`/ctx-attr-vuln`、`/ctx-attr-safe`。

### 3）URL / `href`（本质是「导航目标」，不是普通正文）

- **拼法**：`<a href="${q}">…</a>`
- **风险**：`q` 可以是 **`javascript:alert(1)`**、`data:...` 等，**不依赖尖括号**也能执行或加载危险内容。
- **为何「仅靠 htmlEscape」不够**：`htmlEscape` 主要动 `& < > "'`，**不会**把 `javascript:` 变成安全链接。
- **常见修**：**协议/方案白名单**（只允许 `http:`、`https:`、或受控的相对路径等），**禁止** `javascript:`、`data:`（视业务）等。
- **路由**：`/ctx-href-vuln`、`/ctx-href-safe`。

### 4）脚本上下文（`<script>` 里或事件属性里的「JS 字符串」）

- **拼法（错误示范）**：`<script>var x = "${q}"</script>` 或事件属性里拼用户输入。
- **风险**：`q` 里用 `"`、`</script>` 等 **打断 JS 语法**，直接执行代码。
- **为何不能靠 `htmlEscape` 糊弄**：那是 **HTML 层**规则；这里要 **JS 字符串转义规则**，或 **根本不要把用户数据写进脚本**。
- **较安全演示**：用 **`JSON.stringify(q)`** 生成 **JS 字面量**（仍要谨慎，生产应用优先 **JSON 接口 + 前端不 eval**）。
- **路由**：`/ctx-js-vuln`、`/ctx-js-safe`。

### 5）富文本（允许部分标签，如 `<b>`、`<img>`）

- **需求**：不能只整段 `htmlEscape`，否则 `<b>` 也会变纯文本，业务要展示格式。
- **做法**：**白名单净化**（浏览器端 **DOMPurify** / 公司 **filterXSS** 等），只留安全标签与属性。
- **本仓库 Node 演示**：`/ctx-rich-vuln` 仍用「整段进 div」展示风险；`/ctx-rich-safe` 用 **极简教学用** 规则（仅允许 `<b>...</b>`）说明「与 `htmlEscape` 整段封杀不同」，**生产请用成熟库**。
- **路由**：`/ctx-rich-vuln`、`/ctx-rich-safe`。

## 阶段 3：CSP 与框架

### CSP（内容安全策略）

- **作用**：即使某处 **漏编码**，限制 **脚本从哪加载、是否允许内联脚本/事件**，**减轻**危害。
- **不能替代**：正确的 **encode / sanitize**（策略配错或绕过仍可能出事）。
- **演示**：路由 **`/csp-demo`**（响应头带一条极简 CSP，页面含内联脚本/事件，观察浏览器拦截）。

### 框架（React / Vue）

- **要点**：默认文本绑定多 **自动转义**；**危险 API**（`dangerouslySetInnerHTML`、`v-html`）等于 **主动把字符串当 HTML**。
- **交付**：本文件下节表格 + 可选日后 **Vite 单页**验证。

| 技术 | 相对安全默认 | 高危汇点 |
|------|----------------|----------|
| React | 子节点文本 | `dangerouslySetInnerHTML={{ __html }}` |
| Vue | `{{ }}` 文本 | `v-html`、渲染函数里 `innerHTML` |
